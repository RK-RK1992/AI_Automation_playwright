Manual Test Case: Successful Product Order Placement

Test Case ID: TC-01
- Title: Verify user can log in, add a product to cart, place an order, and confirm it in order history
- Preconditions:
  - Application is up and accessible
  - Valid login credentials are available
  - Product is available in the catalog
  - Country and coupon data are valid

Test Steps:
1. Open the application home page.
2. Enter a valid username and password.
3. Click login.
4. Search for the desired product by name.
5. Add the product to the cart.
6. Navigate to the cart.
7. Verify the selected product is displayed in the cart.
8. Click Checkout.
9. On the checkout page, verify the selected product is still displayed.
10. Enter card details.
11. Apply the valid coupon.
12. Verify the email field matches the logged-in user.
13. Select the target country from the dropdown.
14. Click Submit.
15. Capture the generated order ID.
16. Navigate to the Orders page.
17. Search for the captured order ID.
18. Verify the order ID appears in order history.

Expected Result:
- Login is successful.
- Product is added to cart without error.
- Cart shows the correct product.
- Checkout page loads correctly.
- Card details are accepted.
- Coupon is applied successfully.
- Email is prefilled correctly.
- Country selection works.
- Order is successfully placed.
- Order ID is generated and visible in the order history page.
- The searched order ID matches the generated order ID.

Additional data-driven scenario:
- The spec loops through multiple datasets from the JSON test data file, so the same manual flow should be repeated for each product/country combination.
- Example validations:
  - Product name changes per dataset
  - Country selection changes per dataset
  - Order placement succeeds for all valid data sets

Optional second manual scenario:

  - Login with custom test data

  - Navigate to cart
  - Verify product is added successfully
  - Proceed to checkout
  - Expected: Product is added and checkout flow starts without issues
